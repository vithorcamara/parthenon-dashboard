# 🏛️ O Significado do Nome — Parthenon Dashboard

## Origem do Nome

O nome **Parthenon** é inspirado no **Partenon de Atenas**, um dos maiores símbolos de arquitetura, organização e centralidade da Grécia Antiga. Historicamente, o Partenon não era apenas uma construção, mas um **centro cultural, político e simbólico**, projetado para representar equilíbrio, ordem e propósito.

Essa ideia se conecta diretamente com a proposta do projeto:  
**Parthenon Dashboard** não é apenas um launcher, mas um **sistema central** para a experiência do usuário no PlayStation 2.

---

## Parthenon como Sistema

Assim como o Partenon servia como o núcleo de Atenas, o **Parthenon Dashboard** atua como o núcleo do ambiente do PS2, sendo responsável por:

- Centralizar **jogos, aplicativos e mídia**
- Gerenciar **fluxos de navegação**
- Oferecer uma **experiência de sistema**, e não apenas de aplicativo
- Servir como ponto de partida para soluções externas já consolidadas

A proposta do projeto **não é reinventar tudo do zero**, mas sim **orquestrar** e **integrar** ferramentas existentes da cena PS2, como:

- **OPL (Open PS2 Loader)** para jogos
- **LaunchELF** para utilitários e gerenciamento
- **Popstarter** para títulos de PS1
- Outros homebrews e aplicativos da comunidade

O Parthenon Dashboard funciona como a **camada de experiência do usuário**, enquanto essas ferramentas atuam como os “pilares” que sustentam o sistema.

---

## Relação com AthenaEnv

O projeto é construído sobre o **AthenaEnv**, utilizando **JavaScript** como linguagem principal. Essa escolha reforça dois princípios importantes do Parthenon Dashboard:

- **Acessibilidade no desenvolvimento**  
  JavaScript reduz a barreira de entrada para novos contribuidores em comparação com C/C++.

- **Agilidade e experimentação**  
  Permite iterar rapidamente sobre UX, UI e lógica de sistema, algo essencial para um projeto comunitário.

Nesse contexto, o AthenaEnv atua como a **fundação técnica**, enquanto o Parthenon Dashboard constrói a **estrutura visível e funcional** do sistema.

---

## Como o Nome Conversa com a UI

A identidade de **Parthenon Dashboard** se reflete diretamente na interface:

- **Dashboard como um espaço arquitetônico**  
  A UI é organizada em hubs bem definidos, com navegação horizontal clara e previsível.

- **Sensação de estrutura e ordem**  
  Cada seção (Jogos, Apps, Mídia, Configurações) funciona como uma “ala” do sistema, mantendo consistência visual e comportamental.

- **Minimalismo funcional**  
  Assim como a arquitetura clássica valoriza forma e função, a interface prioriza clareza, legibilidade e foco no conteúdo.

- **Sistema vivo e expansível**  
  O dashboard é pensado para crescer: novos módulos, temas, perfis de usuário e funcionalidades podem ser adicionados sem comprometer a base.

---

## Parthenon Dashboard como Projeto Comunitário

Embora seja um projeto pessoal, o **Parthenon Dashboard** nasce com uma visão clara de **comunidade**:

- Um sistema feito **para o PS2**, respeitando suas limitações
- Construído sobre ferramentas conhecidas da cena homebrew
- Aberto à contribuição, customização e evolução contínua

O nome **Parthenon** representa exatamente isso:  
um espaço construído coletivamente, sólido em sua base e preparado para atravessar o tempo.
